# رغد – رحلتي نحو التفوق (v0.1 – نواة تعمل)

## المنفَّذ فعليًا
- 5 تبويبات (RTL + Material 3 + فاتح/داكن)
- مكتبة من JSON (`assets/content/sample_content.json`) – **محتوى تجريبي وليس منهجًا رسميًا**
- محرك اختبار: خلط، تصحيح، تفسير، حفظ XP والمحاولات، مراجعة الأخطاء
- لعبة الذاكرة
- اختبارات وحدة + GitHub Actions يبني APK

## لم يُنفَّذ بعد (بصراحة)
المنهج الرسمي 2026/2027، CMS، لوحة ولي الأمر، المساعد الذكي، المزامنة السحابية، الصوت، التكيّف/المراجعة المتباعدة.

## البناء
GitHub ← Actions ← Build ← تحميل artifact `raghad-apk`.
محليًا: `flutter create . --platforms=android && flutter pub get && flutter run`
